# LaMa's dependency block.
#
# REQUIRES PYTHON 3.11. This is not a style preference — LaMa is a 2021
# codebase and its import graph is entangled: `load_checkpoint` lives in
# `training/trainers`, which imports the evaluator at module scope, which
# imports the perceptual metrics, which import an augmentation stack. The
# closure ends at:
#
#     albumentations <1.0  ->  imgaug  ->  numpy <2.0
#
# and numpy <2.0 is incompatible with torch 2.x and OpenCV 5 on Python
# 3.12+. Both Dockerfiles pin python:3.11-slim so this resolves; a bare
# install on a newer interpreter will get as far as importing LaMa and
# then fail on `np.sctypes was removed in NumPy 2.0`.
#
# SAM 2 and Grounding DINO have no such constraint — only AI Remove does.
